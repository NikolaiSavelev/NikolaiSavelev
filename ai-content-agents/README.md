# AI Content Agents — СантехСила + Системный маркетинг

Автономная AI-редакция для двух каналов:
- MAX: `channel_Santehsila` — инженерные системы и сантехнические услуги в Москве и МО.
- Telegram: `@biznesss_life` — системный маркетинг, UDS, CRM, AI и автоматизация бизнеса.

## Команда агентов

1. **Research UDS** — обновляет базу знаний по UDS, удержанию клиентов, лояльности, CRM, сегментации, рефералам и повторным продажам.
2. **Research Engineering** — обновляет базу знаний по водоснабжению, отоплению, канализации, тёплым полам, коллекторным системам и материалам.
3. **SMM Strategist** — планирует контент, балансирует пользу/доверие/продажи и исключает повторы.
4. **Copywriter Seller** — пишет живые посты и мягкие CTA.
5. **Visual Director** — формирует промпты для генерации премиальных изображений.
6. **Editor** — проверяет факты, тональность, повторы, цены и рискованные обещания.
7. **Publisher** — публикует в Telegram и MAX.
8. **Analyst** — сохраняет статистику и учит стратегию на результатах.

## Редакционная система v2

Стратег → автор → независимый редактор → факт-чекер → визуальный директор → согласование владельца в Telegram → публикация → аналитика. Подробно: `agents.md`, промпты ролей: `master-content-prompt.md`.

- 3 публикации в неделю на бренд (Вт / Чт / Сб), 12–13 в месяц, по месячным планам.
- Content memory: агент помнит тему, начало, драматургию, нишу, медиа и CTA последних постов и не повторяется.
- Quality gate: human ≥ 9, non-AI ≥ 9, trust ≥ 9, originality ≥ 8, остальное ≥ 8.
- MEDIA DECISION: картинка генерируется только для AI-форматов; для реальных объектов агент просит фото.
- OWNER_DATA_REQUIRED: если посту нужны реальные факты — черновик приходит с вопросом, владелец отвечает, пост переписывается.

## Согласование в Telegram

Задайте `OWNER_CHAT_ID`. Черновики приходят владельцу от того же бота с кнопками «Опубликовать», «Без картинки», «Другой вариант», «Отклонить». Ответ на черновик текстом — реальные данные для переписывания; ответ фотографией — реальное фото к посту. Команды: `/marketing`, `/santeh`, `/queue`.

## Хранилище

`DATA_DIR=/data` на Railway volume — очередь, content memory, research, метрики и фото владельца переживают перезапуски.

## Безопасный режим запуска

Первые 7–10 дней: `APPROVAL_MODE=true`. Агент готовит пост, визуал и CTA, но ждёт ручного подтверждения. После проверки качества можно переключить на автопубликацию.

## Секреты

Никогда не коммитить токены. Использовать только переменные окружения:

```env
OPENAI_API_KEY=
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHANNEL=@biznesss_life
MAX_ACCESS_TOKEN=
MAX_CHANNEL_ID=
APPROVAL_MODE=true
```

## Важный принцип

Агенты не придумывают характеристики, цены, акции, технические нормы и кейсы. Любой меняющийся факт должен браться из актуальной базы знаний/официального источника или отмечаться как требующий проверки.
